Before You Run.

Someone sent you a coding exercise. See which commands the project can run during npm install before you open it on your laptop.

Your browser reads public files from GitHub. It never runs the project.

What this checks

The root package’s npm install hooks and its default native build. Dependencies, scripts called by those hooks, editor tasks, and the sender’s identity are outside this check. An empty list cannot establish that a download is safe.

If the offer was unexpected, confirm the assignment through the company’s own website or a contact you already know before running it.
